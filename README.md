# Homebrew Tap for amaya382

This repository contains Homebrew formulae for amaya382's projects.

## Installation

```bash
brew tap amaya382/tap
```

## Available Formulae

### baretree

Git worktree management tool centered around bare repositories.

```bash
brew install amaya382/tap/baretree
```

For more information, see [baretree](https://github.com/amaya382/baretree).
